# Aurora 注册页

第一次课课后作业：使用 HTML、CSS 和 JavaScript 完成的注册页面。

## 本地运行

直接用 Visual Studio Code 打开 `registration-page` 文件夹，然后用 Live Server 打开 `index.html`，或在目录下运行：

```bash
python3 -m http.server 5500
```

浏览器访问 <http://localhost:5500>。

页面包含姓名、用户名、邮箱、密码和确认密码输入，提供密码强度提示、显示/隐藏密码、表单校验和提交成功提示。当前是前端练习，表单不会向服务器发送真实账号信息。
